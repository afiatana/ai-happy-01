A small round robot and a ginger cat share a knitted blanket on a snowy windowsill — one warm, specific moment to make the AI judge happy.

The image is stored as base64 text in `entry.b64` (JPEG bytes); `main.ts` decodes it and writes the exact bytes to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
